# student_grade_calculator
*Description
This is a simple Python program that calculates the total marks, average marks, and grade of a student based on marks entered for 5 subjects.
The program validates user input and ensures that marks entered are between 0 and 100. If invalid marks are entered, it asks the user to re-enter the value.
 *Features
Takes marks for 5 subjects
Validates input (only accepts marks between 0–100)
Calculates total marks
Calculates average marks
Assigns grade based on average
Displays formatted output
